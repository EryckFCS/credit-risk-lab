# Case Study 05 — EDA: SBS Ecuador Credit Portfolio

## Overview

Exploratory data analysis of the Ecuadorian banking system credit portfolio using public data from the Superintendencia de Bancos del Ecuador (SBS). Focus on credit quality trends, non-performing loan (NPL) ratios, and sectoral breakdowns.

## Status

📋 **Planned**

## Scope

- NPL ratio evolution by institution type (private banks, cooperatives, public banks)
- Sectoral credit allocation vs. GDP contribution
- Geographic distribution of credit
- Credit quality indicators: cartera en riesgo, provisiones, morosidad

## Data Source

- [SBS Ecuador — Estadísticas](https://www.superbancos.gob.ec/bancos/estadisticas/)
- [Banco Central del Ecuador — Sector Financiero](https://www.bce.fin.ec/estadisticas/)

## Dataset: UCI Default of Credit Card Clients

| Field | Value |
|---|---|
| **Source** | [UCI ML Repository #350](https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients) |
| **Original paper** | Yeh, I. C., & Lien, C. H. (2009). *The comparisons of data mining techniques for the predictive accuracy of probability of default of credit card clients.* Expert Systems with Applications, 36(2), 2473–2480. |
| **Observations** | 30,000 credit card clients (Taiwan, April–September 2005) |
| **Features** | 23 input features + 1 binary target |
| **Target** | `DEFAULT` — 1 if client defaulted in October 2005 |
| **Base rate** | ~22.1% |
| **License** | CC BY 4.0 |

## Download

The notebooks fetch the dataset automatically via `ucimlrepo`:

```python
from ucimlrepo import fetch_ucirepo
raw = fetch_ucirepo(id=350)
```

A local Parquet cache is saved to `data/uci_credit_default.parquet` after the first run (ignored by `.gitignore`).

## Variable Dictionary

| Variable | Type | Description |
|---|---|---|
| `ID` | int | Client ID (drop before modeling) |
| `LIMIT_BAL` | float | Credit limit (TWD) |
| `SEX` | cat | 1=Male, 2=Female |
| `EDUCATION` | cat | 1=Graduate, 2=University, 3=High School, 4=Others, {0,5,6}=Unknown |
| `MARRIAGE` | cat | 1=Married, 2=Single, 3=Others, {0}=Unknown |
| `AGE` | int | Age in years |
| `PAY_1–6` | ord | Repayment status t to t-5: -2=no balance, -1=paid, 0=revolving, 1–8=months delayed |
| `BILL_AMT1–6` | float | Statement balance t to t-5 (TWD) |
| `PAY_AMT1–6` | float | Payment amount t to t-5 (TWD) |
| `DEFAULT` | binary | 1 = defaulted in next month (target) |

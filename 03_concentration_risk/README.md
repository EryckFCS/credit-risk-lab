# Case Study 03 — Concentration Risk: Sector Analysis

## Overview

Analysis of credit portfolio concentration risk using official data from the Superintendencia de Bancos del Ecuador (SBS). Covers sectoral, geographic, and single-borrower concentration, with stress testing simulations.

## Status

📋 **Planned**

## Methodology (Planned)

| Metric | Description |
|--------|-------------|
| HHI (Herfindahl-Hirschman Index) | Portfolio concentration by sector/borrower |
| CR5 | Concentration ratio of top 5 exposures |
| Single-name concentration | Regulatory large exposure limits |
| Stress testing | Sector shock scenarios (agricultural, petroleum, real estate) |

## Data Source

- [SBS Ecuador — Boletín Financiero Mensual](https://www.superbancos.gob.ec/bancos/estadisticas/)
